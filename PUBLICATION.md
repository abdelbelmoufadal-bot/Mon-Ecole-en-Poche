# Publication GitHub Pages

Le site est statique. Les fichiers index.html, assets et courses sont prêts à être servis à la racine du dépôt, y compris sous /Mon-Ecole-en-Poche/.

Dans Settings > Pages, choisir Deploy from a branch, puis main et / (root), et enregistrer. L’adresse attendue est https://abdelbelmoufadal-bot.github.io/Mon-Ecole-en-Poche/ une fois le déploiement terminé.

Les voix enregistrées utilisent le navigateur ; le mode Windows local ne s’active pas sur GitHub Pages. Les progrès sont conservés sur chaque navigateur. Pour transférer ceux du site local vers le site en ligne, utiliser l’export/import familial.

Les PDF originaux, archives HTML, outils d’analyse locaux, node_modules et fichiers temporaires sont conservés dans le projet local et exclus de cette copie de publication. Les pages des livres utilisées par l’application sont incluses sous forme d’images, ainsi que les MP3 nécessaires.
